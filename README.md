# Customer Retention Intelligence System

A multi-phase customer churn project covering data preparation, SQL analysis, pipeline processing, a web dashboard, churn prediction, and AI-assisted risk review.

## Project Areas

- `Phase_1` - Customer data cleaning and feature generation
- `Phase_2` - SQL analysis exercises
- `Phase_3` - Project entry point
- `Phase_4/customer-dashboard` - React customer dashboard
- `Phase_5` - Data engineering and pipeline exercises
- `Phase_6` - Churn models and prediction scripts
- `Phase_7` - Risk scoring and AI workflow utilities

## Dashboard

```powershell
cd Phase_4/customer-dashboard
npm install
npm start
```

## Data and Outputs

The project uses `customer_churn.csv` as its source dataset. Generated caches, frontend build files, logs, and reproducible Spark/Parquet outputs are excluded by `.gitignore`.
